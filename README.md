## 常见问题

**优惠码在哪里输入？**

优惠码输入位置在订单结算页面，不是在套餐选择页面。具体步骤：选择套餐和付款周期后点击"立即购买"，跳转到购物车或订单确认页面，在订单结算页面找到"优惠码"或"促销代码"输入框，输入对应的优惠码（如 `ZOROYear`），点击"验证"或"应用"，确认价格已变更为折后价格后再完成支付。

**优惠码可以叠加使用吗？**

不可以。一个订单只能使用一个优惠码。如果你同时拥有月付 9 折码和年付 7.5 折码，选择年付后只能用年付码，不能叠加使用。

**续费时还能继续用优惠码吗？**

可以。`ZORO`、`ZOROQuarter`、`ZOROYear` 都是循环优惠码，续费时可以继续使用同样的折扣。这是 ZoroCloud 的一个优势，不会出现首年便宜、第二年恢复原价的情况。

**为什么输入优惠码后价格没变？**

可能是你选择的套餐不支持优惠码。新加坡住宅、英国家宽住宅、美国 ATT 家宽（US-Astra 系列），以及所有 Mini 系列套餐（US-CERA-Mini、US-9929-Mini）都无法使用优惠码。如果你选的是这些套餐，输入优惠码后系统会提示不适用，价格不会改变。

**支持哪些支付方式？**

ZoroCloud 支持支付宝和微信支付，国内用户购买很方便。

**可以退款吗？**

大部分云服务器支持 24 小时无理由退款（无滥用行为的前提下）。US-9929 系列明确标注退款金额可以原路退回。但美国 ATT 家宽（US-Astra 系列）、新加坡住宅 IP 系列、英国家宽住宅系列明确标注无退款服务，购买前需要确认好配置和使用场景。

所有套餐都强调请勿设置弱密码。如果因为弱密码导致服务器被入侵或删除，官方不提供退款。这个限制在购买页面会明确提示。
